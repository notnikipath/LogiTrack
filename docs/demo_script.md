# Demo Script

1. Open `http://localhost:5177` and show the dispatcher dashboard
2. Open gateway Swagger at `http://localhost:8480/docs`
3. Call `POST /workflow/assign-route` for `ORD-DEMO`
4. Refresh the frontend and show the assigned route and vehicle
5. Call `POST /telemetry/ingest` with overspeed sample
6. Refresh the dashboard and show driver violation alerts
7. Show warehouse zones and inventory widgets
8. Show integration history and analytics KPI
